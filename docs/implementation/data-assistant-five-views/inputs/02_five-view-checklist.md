## 02｜统一执行页与内容分配

### 2.1 必须复用的壳层

Logo、导航、任务身份、历史对话、Xino 身份、消息流、输入框、工作区开关/返回、字体和间距使用同一组现有组件与样式变量。

1920 × 1080 是设计验收基准，不是生产固定像素布局。五图之间的生成尺寸差异不得变成五套 CSS。先核对现有壳层与母版；不重新绘制 Logo，不另装一套字体来伪装“像截图”。

工作区关闭时对话自然占用主区域，不留空白占位栏；打开时只调整同一壳层的空间分配，不换导航、不新建助手、不创建另一个 Task。

### 2.2 对话区：完成回答与轻量推进

可以呈现：直接文字、指标数值、紧凑表格、单一问题的小图、必要选择、真实状态、当前对象的轻摘要与操作。

呈现一轮时，先回答用户的问题，再保留理解答案必需的时间、对象、单位、口径和限制。不是每轮都输出“答案卡 + 条件卡 + 证据卡 + 操作卡”。

不默认铺开完整字段、SQL、长日志、权限矩阵、全量候选或整份报告。用户只问少量字段且有权读取时，可直接回答，不为两行内容强制展开工作区。

### 2.3 右侧：完整对象与深入操作

承载本次计算方案、完整结果、对应定义/依据和用户明确要求的对象详情。标题与范围在当前对象上明确，主体按对象差异化，底部只保留确有意义的动作。

不把计划、结果、依据、资源、权限全部固定为常驻 Tab。进入依据后仍使用同一工作区，返回原结果及原视图；不叠加第二个右侧栏。

### 2.4 紧凑与展开共用结果

| 情境 | 处理 |
| --- | --- |
| 一个数值或清楚的小表/小图能直接回答 | 在对话中交付，右侧可以关闭。 |
| 已明确要求完整结果、完整数据或需要深入操作 | 打开对应对象工作区；对话仍给直接结论，不只写“请看右侧”。 |
| 返回时工作区已经展示本次结果 | 可以保留短摘要或紧凑小表，不再默认复制完整图、全量表和全部依据。 |
| 用户先在对话得到小图，后来展开 | 保留原消息；展开读取同一结果，不删除、重写历史答案。 |
| 用户要求画简单比较图但没要求展开 | 可内嵌小图；不要求再点“生成图表”。 |
| 对话宽度不足以清楚展示 | 用结果摘要与显式展开承接，不能缩小字体到难以阅读。 |
| 用户等待期间关闭/转看其他对象 | 结果仍归属原请求，提示已可查看，不抢回面板、不替换当前对象。 |

同一结果的数值、单位、舍入、缺失值含义与范围必须一致。紧凑表可以选择较少列，但必须标明必要口径；不能把有限预览说成完整范围。

“内嵌 → 展开 → 返回”是同一个对象的查看方式，不是第二次查询。切换视图、开关面板可以沿用既有查看/审计事件，但不能触发搜索、计算或业务条件版本变更。

## 05｜五图逐项实施合同

### 05.1 图 01：正式指标直接回答

**入口与条件：**当前请求为“查询 2026 年 8 月浦锦街道的 60 岁及以上常住人口数”；指标已唯一确定或由指标入口带入；既有执行校验成立后取得对应结果。

**对话：**

> 2026 年 8 月，浦锦街道 60 岁及以上常住人口为 **20,000 人**。

辅助行：`2026 年 8 月末统计 · 设计演示数据，非真实业务统计`。一个入口：`查看指标口径`。不新增大 KPI 卡，右侧默认关闭。

**动作绑定：**“查看指标口径”绑定这份答案实际使用的 `M-P` 定义引用，不是单纯按“人口”文本再次检索。只读取有权定义；读取失败就在相应对象位置说明，不影响已存在结果，不自动执行新的查询。

**必要分支：**用户只问指标定义时，不强迫补统计时间，不出现 20,000 的查数答案。定义能看但数值无权限时仍可解释定义，不能补数或显示 0。

**成功证据：**实际指标查询返回的结果及其范围。演示模式只说明演示返回，不声称真实资源查询成功。

### 05.2 图 02：指标口径澄清

**已知：**2026 年 8 月、七宝镇。**未知：**采用 `M-B` 还是 `M-A`。用现有决策组件展示 `D-B`。

> 你要看在营可用床位，还是核定床位？两种口径的数值和含义不同。

| 选项 | 说明 |
| --- | --- |
| 在营可用养老床位数 | 用于了解本口径下的在营可用容量。 |
| 养老床位核定数 | 用于了解核定容量，不等于实际可用容量。 |

主按钮：`使用此口径继续查询`。

| 状态 | 行为 |
| --- | --- |
| 未选择 | 两项空心单选；提交禁用；右侧关闭；无查询数值。 |
| 已选择但未提交 | 仅保存本地选择，启用提交，不修改正式定义或发起查询。 |
| 提交中 | 防重复，保留选择，不提前收拢。 |
| 提交成功 | 当前决策变为已确认后收拢，按原查询/确认规则继续。确认成功不等于查询已成功。 |
| 提交失败 | 保留选择与错误，允许原动作重试。 |
| 需求变化、问题失效 | 只读失效摘要，不能提交旧问题。 |

历史选择的展开/收拢不改业务条件。不得依据查询权限高低代选口径。若现行策略另有必须确认的执行动作，不以本按钮绕过。

演示查询成功后，对应七宝镇在营值为 800 张、核定值为 1,000 张；这些值不得提前出现在待选择组件中。

| --- | --- | --- | --- | --- |

| 调整条件 | 明确承接对象与正式变化值 | 提交后走既有需求与计划变更 | 变化范围明确 | 不写回正式指标、不覆盖历史。 |
